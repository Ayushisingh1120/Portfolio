# Ayushi Singh — Portfolio Website

A modern, responsive personal portfolio for **Ayushi Singh**, Generative AI & AI Agent Engineer.

## 🚀 Features
- **Design & Layout**: Glassmorphism aesthetic, midnight-indigo theme, responsive layout, and smooth animations.
- **Hero & Identity**: Interactive `$ whoami` terminal typing animation, custom photo with morphing glowing aura, and quick social links.
- **Project Deep-Dives**: Interactive tabbed cards (*Overview*, *The Thinking*, *System Design*, *Tech & Stats*) for:
  - **CareCRM AI** — AI CRM & Customer Support Copilot
  - **EnterpriseIQ** — Enterprise RAG Knowledge Assistant
  - **Guardio** — Credit Card Fraud Detection Pipeline
- **Skills Matrix & Certifications**: Categorized technical stacks (GenAI & Agents, ML/DL, Languages, Backend/APIs, Databases/Analytics) and credentials in GenAI, Python, SQL, and HTML5.
- **Interactive Tools**: Command palette modal (`Ctrl+K`), theme switcher (dark/light), and direct resume viewer/downloader.

## 📁 Included Files
- `index.html` — Main website structure
- `style.css` — Custom design tokens, glassmorphism, responsive styles
- `script.js` — Terminal typewriter, tabs, command palette, and smooth scroll
- `avatar.jpg` — Headshot photo
- `avatar.svg` — Fallback vector avatar
- `resume.pdf` — Full academic and technical resume PDF

## 💻 How to Run Locally
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).

## 🌐 How to Deploy to Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside this directory and follow the prompts.
Alternatively, upload this folder or repository to GitHub and link it directly via the [Vercel Dashboard](https://vercel.com).
